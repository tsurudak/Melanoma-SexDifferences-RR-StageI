This repo contains the power analyses described in:

Tsuruda KM, Reis Costa D, Conforti F, Pala L, Robsahm TE, Winge-Main AK, Andreassen BK. **Sex-disparities in survival after anti-PD-1 monotherapy for advanced melanoma in Norway: a population-based cohort study [Registered Report - stage I].** J Clin Epidemiol. https://doi.org/10.1016/j.jclinepi.2026.112482


**RegisteredReport-PowerCalculation.qmd** -> is the code used to run the power analyses and generate RegisteredReport-PowerCalculation.md and the figures saved in Melanoma-SexDifferences-RR-StageI/RegisteredReport-PowerCalculation_files/

**RegisteredReport-PowerCalculation.md** -> provides the results of our analyses in a format that can be viewed here on GitHub
